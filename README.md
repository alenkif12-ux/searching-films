# 🎬 CineSearch — Movie Search App

A modern, responsive web application built with vanilla JavaScript and SCSS that allows users to search for movies in real-time using the OMDb API. Designed with a sleek dark theme optimized for all screen sizes—from mobile phones and tablets to desktop monitors and smart TVs.

## 🚀 Live Demo
Check out the live version here: [Watch the project](https://alenkif12-ux.github.io/searching-films/)

---

## ✨ Features
- **Real-Time Search:** Instant movie lookups as you type.
- **Responsive Layout:** Adaptive CSS Grid layout tailored for mobile devices, tablets, laptops, desktops, and large TV screens.
- **Robust Error Handling:** Clean feedback states for loading, empty inputs, and "Movies not found" scenarios.
- **Poster Fallbacks:** Graceful error handling (`onerror`) for broken or missing image links from the API.
- **Modern SCSS Architecture:** Organized styles using variables, nesting, and media queries compiled with Sass.

---

## 🛠️ Tech Stack
- **JavaScript (ES6+)**: Async/Await, Fetch API, DOM manipulation.
- **SCSS (Sass)**: Modular styling and responsive mixins/media queries.
- **HTML5**: Semantic markup.
- **OMDb API**: External movie database provider.
